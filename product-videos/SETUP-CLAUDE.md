# تعليمات تثبيت المشروع (لـ Claude Code)

> **للمستخدم:** افتح Claude Code (أو تبويب Code في Claude Desktop) على فولدر `product-videos`، واكتبله:
> **«اقرأ ملف SETUP-CLAUDE.md ونفّذ اللي فيه خطوة بخطوة»**

---

## يا Claude: المطلوب منك

ثبّت مشروع فيديوهات الإعلانات ده على الجهاز، واتأكد إنه شغال، وبعدين عرّف المستخدم يستخدمه إزاي. **المستخدم مش مبرمج**، فكلّمه بالعامية المصرية وبكلام بسيط، ومن غير مصطلحات تقنية إلا لو هتشرحها.

### قواعد أثناء التثبيت
- **متعدّلش أي ملف في `src/` أو `scripts/`.** التثبيت بس.
- قبل أي أمر بيسطّب حاجة على الجهاز نفسه (برا فولدر المشروع)، **اسأل المستخدم الأول**.
- لو خطوة فشلت، دوّر على الحل في جدول «لو حاجة طلعت غلط» في `README.md`. ولو مش موجود، اشرح المشكلة للمستخدم ببساطة واقترح الحل، ومتكمّلش من غير ما تقوله.
- في الآخر، قوله بوضوح أنهي خطوات نجحت وأنهي لأ.

### الخطوة 1: اتأكد إنك في فولدر المشروع
- لازم يكون فيه `package.json` و`CLAUDE.md` و`src/`.
- **لو مش موجودين:** المشروع لسه متنزلش. اسأل المستخدم:
  - يا إما ينزّل ملف `product-videos.zip`، ويفك الضغط، ويفتح فولدر `product-videos`.
  - يا إما تنزّله انت من GitHub (الريبو خاص، فلازم يكون عامل تسجيل دخول في GitHub على الجهاز):
    ```bash
    git clone -b claude/instagram-ads-saudi-strategy-w8mege https://github.com/dentsamer97/New-Idea.git
    cd New-Idea/product-videos
    ```

### الخطوة 2: Node.js
```bash
node -v
```
- لازم تكون **20 أو أحدث**.
- **لو مش متسطّب أو أقدم:** قول للمستخدم ينزّل نسخة **LTS** من **nodejs.org** ويسطّبها زي أي برنامج، ويقفل Claude ويفتحه تاني، وبعدين يكمّل. (أو اعرض عليه تسطّبه انت لو الجهاز فيه winget على ويندوز أو brew على الماك، **بعد ما يوافق**.)

### الخطوة 3: تسطيب المكتبات
```bash
npm install
```
بياخد دقيقة أو اتنين أول مرة.

### الخطوة 4: Skills بتاعة Remotion
```bash
npm run setup:skills
```
- بتعلّمك قواعد Remotion عشان تعدّل في الفيديوهات صح بعد كده.
- لو سألت أسئلة، اختار الإعدادات الافتراضية.
- **لو فشلت، كمّل عادي**، المشروع شغال من غيرها. بس قول للمستخدم.

### الخطوة 5: فحص الكود
```bash
npm run lint
```
لازم يخلص من غير errors.

### الخطوة 6: تجربة حقيقية
```bash
npm run try -- P-sink_A-kashta_F-showcase_H-kq --still 1
```
- **أول مرة** Remotion بينزّل نسخة Chrome خاصة بيه، فبياخد وقت أطول. ده طبيعي.
- لازم يطلع ملف صورة في `out/try/`. **افتحه وبصّ عليه**: لازم يبقى فيه كلام عربي موصول (مش حروف مقطّعة) وصورة المغسلة.
- لو تمام، جرّب فيديو صغير:
  ```bash
  npm run try -- P-sink_A-kashta_F-ugc_H-kq
  ```
  لازم يطلع `out/try/P-sink_A-kashta_F-ugc_H-kq.mp4`.

### الخطوة 7: اقرا المشروع
اقرا `CLAUDE.md` و`README.md` كويس. فيهم القواعد اللي لازم تمشي عليها في أي تعديل جاي، والأوامر كلها.

### الخطوة 8: سلّم للمستخدم
اكتب للمستخدم ملخص قصير بالعامية المصرية:
1. **التثبيت:** إيه اللي نجح، وإيه اللي محتاج منه حاجة.
2. **أهم 5 أوامر** وكل واحد بيعمل إيه في سطر:
   - `npm run dev`: المعاينة في المتصفح
   - `npm run try -- <اسم الإعلان>`: تجربة سريعة
   - `npm run render:all`: طلّع الإعلانات الأساسية
   - `npm run winner -- <اسم الإعلان>`: نسخ من إعلان كسبان (أو قول «وينر»)
   - `npm run clips -- <المنتج>`: اللقطات الحقيقية
3. **إزاي يطلب منك حاجات بالكلام**، بأمثلة:
   - «ضيف منتج جديد» وبعدين يبعت التفاصيل والصور
   - «اعمل فيديو UGC للمغسلة بقالب fresh»
   - «وينر» لما يبقى عنده إعلان كسبان
   - «ضيف اللقطات دي للمنتج» ويبعت فيديوهاته
4. **سعر المغسلة في الملف 99,000 د.ع، وده سعر مؤقت.** اسأله عن سعره الحقيقي.

وفي الآخر اعرض عليه تشغّل `npm run dev` عشان يشوف المعاينة، واديله اللينك اللي هيطلع (غالبًا `http://localhost:3000`).
