# مشروع فيديوهات إعلانات المنتجات

مشروع Remotion بيطلّع إعلانات عمودية لمنتجات الدفع عند الاستلام (العراق والسعودية). كل إعلان = **منتج × زاوية × هوك × فورمات**، وبيتعرض بـ **قالب** (ألوان وخطوط وأشكال).

## القواعد التقنية (ممنوع تكسرها)

- المقاس **1080×1920**، و**30 فريم في الثانية**. الأرقام دي في `src/lib/timing.ts` بس.
- **عربي من اليمين للشمال:** كل مشهد جوه `<Scene>` (فيه `direction: "rtl"`). أي غلاف جديد لازم يحط `direction: "rtl"`.
- **كل حركة محسوبة من `useCurrentFrame()`** بـ `interpolate` أو `spring` أو دوال `src/lib/anim.ts`.
- **ممنوع:** `Math.random`، و`setTimeout` و`setInterval`، و**CSS animation أو transition**. بيعملوا رعشة في الـ MP4. ولو محتاج عشوائي استخدم `random("seed")` من remotion.
- **`interpolate` دايمًا بـ clamp** (`extrapolateLeft` و`extrapolateRight: "clamp"`)، إلا لو المدخل نفسه محصور بين حدين.
- **أي ملف (صورة، لقطة، صوت، خط) لازم يبقى جوه `public/`** ويتقري بـ `staticFile()` بنفس الاسم بالظبط.
- **الخطوط:** بتتحمّل كلها من `public/fonts` في `src/fonts.ts`. متستخدمش خط مش موجود في `fontNames` (`src/themes.ts`).
- **التوقيتات كلها في `TIMING` في `src/lib/timing.ts`.** متكتبش مدة مشهد جوه ملف مشهد أو فورمات.
- **الألوان من القالب** (`theme.text`، و`theme.accent`...). متكتبش لون ثابت زي `"white"` لكلام فوق خلفية القالب، لأن فيه قوالب فاتحة.
- **الـ blur تقيل في الـ render.** للخلفيات المموّهة استخدم `<BlurredMedia>` (بيعمل الـ blur على نسخة صغيرة).
- **الهوك لازم يبقى ظاهر من أول فريم** (`visibleAtStart`)، لأن أول فريم هو صورة الفيديو قبل ما يشتغل.
- بعد أي تعديل شغّل `npm run lint`، وجرّب بـ `npm run try` قبل ما تطلّع فيديوهات كاملة.

## الكلمات اللي بتشغّل أوامر خاصة

| المستخدم يقول | تعمل إيه |
|---|---|
| **«وينر»** أو `/winner` أو «عندي إعلان كسبان» | طبّق skill الـ winner (`.claude/skills/winner/SKILL.md`) خطوة بخطوة |
| **«اختبار زوايا»** | `npm run angles -- <code المنتج>`، والتفاصيل في نفس الـ skill |

**غير كده** (فيديو عادي لمنتج، تعديل تصميم، منتج جديد) اشتغل عادي، **ومتطبقش طريقة الوينر من نفسك**.

## القوالب

8 قوالب في `src/themes.ts`: `night` (ليلي)، و`clean` (فاتح نظيف)، و`bold` (جريء)، و`desert` (صحراوي)، و`neon` (نيون)، و`fresh` (طبيعي أخضر)، و`fun` (مرح)، و`luxury` (فاخر).

- كل قالب بيحدد: الألوان، وخط العناوين وخط الكلام، وشكل البوكسات (`styles`)، وحركة ظهور الكلام.
- المنتج بيختار بـ `theme` في ملفه. **ولو مش مكتوب، بياخد قالب ثابت محسوب من اسمه**، فالمنتجات بتطلع مختلفة.
- `fonts` و`colors` في ملف المنتج بيغيّروا خطوط أو ألوان القالب للمنتج ده بس.
- `--theme <قالب>` في أي أمر = تجربة قالب تاني من غير ما تغيّر الملف. واسم الملف بيبقى آخره `_T-<قالب>`.
- **في الوينر القالب ثابت** في كل النسخ، لأن تغييره = تغيير عنصر رابع.

## الفورمات (الستايلات)

| الفورمات | فيه إيه |
|---|---|
| `showcase` | عرض المنتج كامل (~32 ث، وأطول لو فيه آراء عملاء) |
| `short` | نسخة مختصرة (~14 ث) |
| `static` | صورة ثابتة |
| `ugc` | لقطات ملء الشاشة بقطع سريع وكلام بستايل تيك توك (~20 ث) |
| `compare` | قبل وبعد / مقارنة (~14 ث) |
| `reasons` | 3 أسباب (~17 ث) |
| `pov` | «POV: لما تكون...» ولقطات سريعة (~18 ث) |

- كل الفورمات بتستخدم **اللقطات الحقيقية لو موجودة، ولو مش موجودة الصور**.
- `pov` بياخد الجملة من `angle.pov`. و`compare` بياخد الصفوف من `angle.compare`.

## البيانات الحقيقية بس

دول **بيظهروا بس لو مكتوبين في ملف المنتج. متخترعهمش أبدًا:**
- `reviews`: تقييمات عملاء حقيقية، بتظهر في مشهد «آراء عملائنا» مع Avatar.
- `faq`: أسئلة وأجوبة حقيقية، بتظهر بشكل رسايل واتساب.
- `limited`: جملة ندرة حقيقية (مثلًا «الكمية محدودة»)، بتظهر كشارة في الركن.

## اللقطات الحقيقية (لما المستخدم يبعت فيديوهات للمنتج)

1. حط الملفات في `public/products/<id المنتج>/clips/` بأسامي إنجليزي قصيرة.
2. **اتفرّج على كل فيديو قبل ما تصنّفه:** طلّع منه فريمات بـ ffmpeg (فريم كل ثانية) وبصّ عليها.
3. ضيف كل لقطة في `clips` في ملف المنتج: `role` (hook، problem، before، unbox، demo، feature، result، lifestyle، talking)، و`feature` لو بتوري ميزة معينة، و`angle` لو لزاوية واحدة، و`start` و`end` بالثواني لو الفيديو طويل، و`audio: true` بس لو فيه كلام مهم.
4. شغّل `npm run clips -- <code>` عشان تتأكد.

## الصوت

- **المؤثرات الصوتية** (`public/sfx`) مولّدة جوه المشروع ومن غير حقوق. بتشتغل لوحدها (ووش مع الانتقال، ودينج مع السعر، وبوب مع ضغطة الزرار). `sfx: false` في ملف المنتج بيقفلها.
- **الموسيقى:** `music: "music/<ملف>"` في ملف المنتج، والملف في `public/music`. **بس موسيقى المستخدم عنده حق استخدامها.**

## الأيقونات

أي أيقونة من **Lucide** باسمها (lucide.dev/icons)، زي `truck` أو `gift` أو `shield-check`. والأيقونة `soap` مرسومة جوه المشروع.

## الأوامر

```bash
npm run setup:skills             # أول مرة: Skills بتاعة Remotion لـ Claude
npm run dev                      # المعاينة (Remotion Studio)
npm run try -- <اسم الإعلان>      # تجربة سريعة: أول 3 ثواني بنص الجودة (--from/--to/--still/--theme)
npm run render:all [-- <code>]   # الإعلانات الأساسية
npm run angles -- <code>         # اختبار الزوايا
npm run winner -- <اسم الإعلان>   # نسخ من إعلان كسبان (--formats ugc,static)
npm run clips -- <code>          # اللقطات الحقيقية والأماكن الناقصة
npm run lint                     # فحص الكود
```

## الملفات المهمة

- `src/products/<منتج>.ts`: بيانات المنتج. أي منتج جديد بيتضاف في `src/products/index.ts`.
- `src/themes.ts`: القوالب والخطوط. `src/components/boxes.tsx`: البوكسات (الليبل، والكلمة المميزة، والسعر، وبوكس الدفع، والعدّاد، والـ Avatar، والتقييم، والسؤال والجواب، وشارة الركن).
- `src/lib/timing.ts`: كل التوقيتات. `src/lib/anim.ts`: الحركات (enter، وpop، وblurIn، وentrance).
- `src/formats/`: الستايلات. `src/scenes/`: مشاهد عرض المنتج. `src/StaticAd.tsx`: الإعلان الثابت.
- `src/lib/plan.ts`: الإعلانات الأساسية واختبار الزوايا وخطة الوينر.
- `src/lib/media.ts`: بيختار لكل مكان لقطة حقيقية لو موجودة، ولو لأ صورة.
- `results/ads-log.csv`: دفتر النتايج.

## قواعد المحتوى

- الكلام بلهجة البلد: عراقي للعراق، وسعودي للسعودية.
- متكتبش أي ادعاء عن المنتج مش موجود في وصفه.
- الأسعار من ملف المنتج بس.
