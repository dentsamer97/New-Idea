# مشروع فيديوهات إعلانات المنتجات

مشروع Remotion بيطلّع إعلانات عمودية (9:16) لمنتجات الدفع عند الاستلام (العراق والسعودية). كل إعلان = **منتج × زاوية × هوك × فورمات**.

## الكلمات اللي بتشغّل أوامر خاصة

| المستخدم يقول | تعمل إيه |
|---|---|
| **«وينر»** أو `/winner` أو «عندي إعلان كسبان» | طبّق skill الـ winner (`.claude/skills/winner/SKILL.md`) خطوة بخطوة |
| **«اختبار زوايا»** | `npm run angles -- <code المنتج>`، والتفاصيل في نفس الـ skill |

**غير كده** (فيديو عادي لمنتج، تعديل تصميم، منتج جديد) اشتغل عادي، **ومتطبقش طريقة الوينر من نفسك**.

## الفورمات (الستايلات)

| الفورمات | فيه إيه |
|---|---|
| `showcase` | عرض المنتج كامل (~32 ث) |
| `short` | نسخة مختصرة (~14 ث) |
| `static` | صورة ثابتة |
| `ugc` | لقطات ملء الشاشة بقطع سريع وكلام بستايل تيك توك (~20 ث) |
| `compare` | قبل وبعد / مقارنة: الطريقة القديمة قصاد المنتج (~14 ث) |
| `reasons` | 3 أسباب تخليك تطلب المنتج (~17 ث) |
| `pov` | «POV: لما تكون...» ولقطات سريعة (~18 ث) |

- كل الفورمات بتشتغل مع أي منتج، وبتستخدم **اللقطات الحقيقية لو موجودة، ولو مش موجودة بتستخدم الصور**.
- `pov` بياخد الجملة من `angle.pov`. ولو مش موجودة: «لما تكون الوحيد اللي جايب <اسم المنتج>».
- `compare` بياخد الصفوف من `angle.compare`. ولو مش موجودة: كل مشكلة قصاد ميزة.

## اللقطات الحقيقية (لما المستخدم يبعت فيديوهات للمنتج)

1. حط الملفات في `public/products/<id المنتج>/clips/` بأسامي إنجليزي قصيرة (`unbox.mp4`، `demo-1.mp4`...).
2. **اتفرّج على كل فيديو قبل ما تصنّفه:** طلّع منه فريمات بـ ffmpeg (فريم كل ثانية) وبصّ عليها.
3. ضيف كل لقطة في `clips` في ملف المنتج:
   - `role`: واحد من hook، problem، before، unbox، demo، feature، result، lifestyle، talking.
   - `feature`: لو اللقطة بتوري ميزة معينة، اكتب الـ `id` بتاعها.
   - `angle`: لو اللقطة مناسبة لزاوية واحدة بس.
   - **فيديو طويل:** قسّمه لكذا لقطة من نفس الملف، كل واحدة بـ `start` و`end` بالثواني.
   - `audio: true` بس لو فيه حد بيتكلم وصوته مهم. غير كده سيبها من غير صوت.
4. شغّل `npm run clips -- <code>` عشان تتأكد إن الملفات موجودة، وتشوف الأماكن اللي لسه بتستخدم صور.
5. الأفضل تبقى اللقطات عمودية 9:16. لو أفقية بتتقص من الجناب.

## الأوامر

```bash
npm run dev                      # المعاينة (Remotion Studio)
npm run render:all [-- <code>]   # الإعلانات الأساسية: هوكات أول زاوية بفورمات showcase
npm run angles -- <code>         # اختبار الزوايا
npm run winner -- <اسم الإعلان>   # نسخ من إعلان كسبان (--formats ugc,static لاختيار الفورمات)
npm run clips -- <code>          # اللقطات الحقيقية للمنتج والأماكن الناقصة
npm run lint                     # فحص الكود
```

## الملفات المهمة

- `src/products/<منتج>.ts`: بيانات المنتج (المميزات، الزوايا، الهوكات بالباترن). أي منتج جديد بيتضاف في `src/products/index.ts`.
- `src/lib/plan.ts`: منطق الإعلانات الأساسية واختبار الزوايا وخطة الوينر.
- `src/formats/`: الستايلات (showcase، ugc، compare، reasons، pov). `src/scenes/`: مشاهد عرض المنتج. `src/StaticAd.tsx`: الإعلان الثابت.
- `src/lib/media.ts`: بيختار لكل مكان في الفيديو لقطة حقيقية لو موجودة، ولو لأ صورة.
- `results/ads-log.csv`: دفتر النتايج، وكل إعلان بيطلع بأمر winner أو angles بيتسجّل فيه.

## قواعد

- الكلام في الإعلانات بلهجة البلد: عراقي للعراق، وسعودي للسعودية.
- متكتبش أي ادعاء عن المنتج مش موجود في وصفه.
- الأسعار من ملف المنتج بس.
