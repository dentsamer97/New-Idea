# مشروع فيديوهات إعلانات المنتجات

مشروع Remotion بيطلّع إعلانات عمودية (9:16) لمنتجات الدفع عند الاستلام (العراق والسعودية). كل إعلان = **منتج × زاوية × هوك × فورمات**.

## الكلمات اللي بتشغّل أوامر خاصة

| المستخدم يقول | تعمل إيه |
|---|---|
| **«وينر»** أو `/winner` أو «عندي إعلان كسبان» | طبّق skill الـ winner (`.claude/skills/winner/SKILL.md`) خطوة بخطوة |
| **«اختبار زوايا»** | `npm run angles -- <code المنتج>`، والتفاصيل في نفس الـ skill |

**غير كده** (فيديو عادي لمنتج، تعديل تصميم، منتج جديد) اشتغل عادي، **ومتطبقش طريقة الوينر من نفسك**.

## الأوامر

```bash
npm run dev                      # المعاينة (Remotion Studio)
npm run render:all [-- <code>]   # الإعلانات الأساسية: هوكات أول زاوية بفورمات showcase
npm run angles -- <code>         # اختبار الزوايا
npm run winner -- <اسم الإعلان>   # نسخ من إعلان كسبان
npm run lint                     # فحص الكود
```

## الملفات المهمة

- `src/products/<منتج>.ts`: بيانات المنتج (المميزات، الزوايا، الهوكات بالباترن). أي منتج جديد بيتضاف في `src/products/index.ts`.
- `src/lib/plan.ts`: منطق الإعلانات الأساسية واختبار الزوايا وخطة الوينر.
- `src/scenes/`: مشاهد الفيديو. `src/StaticAd.tsx`: الإعلان الثابت.
- `results/ads-log.csv`: دفتر النتايج، وكل إعلان بيطلع بأمر winner أو angles بيتسجّل فيه.

## قواعد

- الكلام في الإعلانات بلهجة البلد: عراقي للعراق، وسعودي للسعودية.
- متكتبش أي ادعاء عن المنتج مش موجود في وصفه.
- الأسعار من ملف المنتج بس.
