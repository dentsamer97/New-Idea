# فيديوهات إعلانية للمنتجات (Remotion)

مشروع بيطلّع إعلانات **عمودية 9:16** (ريلز / تيك توك / ستوري) لأي منتج، من ملف بيانات بسيط.

كل إعلان = **منتج × زاوية × هوك × فورمات**، واسمه بيقول ده:

```
P-sink_A-kashta_F-showcase_H-kq
P = المنتج   A = الزاوية (Angle)   F = الفورمات   H = الهوك
```

## الفورمات

| الفورمات | المدة | فيه إيه |
|---|---|---|
| `showcase` | ~32 ث | هوك ← المشكلة ← الحل ← المميزات ← الاستخدامات ← السعر ← اطلب الآن |
| `short` | ~14 ث | هوك ← المنتج ← أهم ميزتين ← السعر ← اطلب الآن |
| `static` | صورة | الهوك + المنتج + 3 مميزات + السعر + زرار الطلب |

## التشغيل على جهازك

محتاج **Node.js** (نسخة 20 أو أحدث).

```bash
cd product-videos
npm install                 # أول مرة بس
npm run dev                 # يفتح المعاينة في المتصفح
npm run render:all          # الإعلانات الأساسية (هوكات أول زاوية) في فولدر out
```

## طريقة الـ Winner Creative (بأمر خاص)

الطريقة دي **مبتشتغلش غير لما تطلبها**:

```bash
npm run winner -- P-sink_A-kashta_F-showcase_H-kq          # كل النسخ
npm run winner -- P-sink_A-kashta_F-showcase_H-kq --only hook   # فرع واحد: angle | hook | format
npm run winner -- P-sink_A-kashta_F-showcase_H-kq --dry    # الخطة بس من غير فيديوهات
```

من الإعلان الكسبان بيطلّع نسخ، **كل نسخة بتغيّر عنصر واحد بس**:
- **هوك تاني** لنفس الزاوية والفورمات ← بيختبر الهوك
- **فورمات تاني** لنفس الزاوية والهوك ← بيختبر الفورمات
- **نفس باترن الهوك** (سؤال، فضول، رقم...) على **زاوية تانية** ← بيختبر الزاوية

وفي Claude: اكتب **«وينر»** أو `/winner`، وClaude هيمشي على الطريقة كلها: يحدد الوينر، ويكتب الهوكات الناقصة، ويطلّع النسخ، ويسجّلها.

قبل ما يبقى عندك وينر، تقدر تختبر الزوايا: `npm run angles -- sink`

## دفتر النتايج

`results/ads-log.csv` بيتفتح في Excel. كل إعلان بيطلع بأمر `winner` أو `angles` بيتسجّل فيه، وانت بتملا أرقامه بعد ما يشتغل (الصرف، Hook Rate، CTR، الطلبات، المؤكد، المستلم).

## إضافة منتج جديد

1. حط صور المنتج في `public/products/<اسم-المنتج>/`.
2. انسخ `src/products/portable-sink.ts` لملف جديد وعدّل:
   - `id` و `code`: معرّف المنتج واسمه القصير في أسماء الإعلانات
   - `name` و `tagline` و `price` و `currency` (`IQD` أو `SAR`)
   - `oldPrice` و `offer` (اختياري)
   - `features`: المميزات، كل واحدة بـ `id`
   - `angles`: الزوايا، كل زاوية بمشاكلها وترتيب مميزاتها واستخداماتها
   - `hooks`: الهوكات، كل هوك تابع لزاوية (`angle`) وليه باترن (`pattern`)
3. ضيف المنتج في `src/products/index.ts`.

أو ببساطة قول لـ Claude: «ضيف منتج جديد» وابعتله التفاصيل والصور.
