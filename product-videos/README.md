# فيديوهات إعلانية للمنتجات (Remotion)

مشروع بيطلّع فيديو إعلان **عمودي 9:16** (ريلز / تيك توك) لأي منتج، من ملف بيانات بسيط.
كل منتج بيطلع منه **فيديو لكل Hook** عشان تجربهم في الإعلانات وتشوف أنهي بيبيع أكتر.

## ترتيب الفيديو (حوالي 32 ثانية)

| المشهد | المدة | فيه إيه |
|---|---|---|
| Hook | 3 ث | جملة تشد في أول ثانيتين + صورة المنتج |
| المشكلة | 4 ث | 3 مشاكل بيعاني منها العميل |
| الحل | 3 ث | اسم المنتج + صورته |
| المميزات | 2.4 ث لكل ميزة | صورة + أيقونة + عنوان + شرح |
| الاستخدامات | 3 ث | فين يستخدمه |
| السعر | 4 ث | السعر + العرض + الدفع عند الاستلام |
| الطلب (CTA) | 5 ث | زرار «اطلب الآن» بإيد بتضغط عليه |

## التشغيل على جهازك

محتاج **Node.js** (نسخة 20 أو أحدث).

```bash
cd product-videos
npm install          # أول مرة بس
npm run dev          # يفتح المعاينة في المتصفح
npm run render:all   # يطلّع كل الفيديوهات MP4 في فولدر out
```

لمنتج واحد بس: `npm run render:all -- portable-sink`

## إضافة منتج جديد

1. اعمل فولدر للصور: `public/products/<اسم-المنتج>/` وحط فيه صور المنتج.
2. انسخ `src/products/portable-sink.ts` لملف جديد وعدّل البيانات:
   - `name` و `tagline`: اسم المنتج والجملة اللي تحته
   - `price` و `currency`: السعر والعملة (`IQD` أو `SAR`)
   - `oldPrice` و `offer` (اختياري): سعر قبل الخصم، وعرض زي «قطعتين بـ ...»
   - `hooks`: جمل البداية (كل واحدة = فيديو مستقل)
   - `problems` و `features` و `uses`: المشاكل والمميزات والاستخدامات
   - `cta.whatsapp` (اختياري): رقم واتساب يظهر في الآخر
   - `theme`: ألوان الفيديو
3. ضيف المنتج في `src/products/index.ts`.

أو ببساطة قول لـ Claude: «ضيف منتج جديد» وابعتله التفاصيل والصور.
