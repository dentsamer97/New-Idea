# فيديوهات إعلانية للمنتجات (Remotion)

مشروع بيطلّع إعلانات **عمودية 9:16** (ريلز / تيك توك / ستوري) لأي منتج، من ملف بيانات بسيط.

كل إعلان = **منتج × زاوية × هوك × فورمات**، واسمه بيقول ده:

```
P-sink_A-kashta_F-showcase_H-kq
P = المنتج   A = الزاوية (Angle)   F = الفورمات   H = الهوك
```

## أول مرة؟ ابدأ من هنا

| الكلمة | معناها |
|---|---|
| **Claude Code** | نسخة من Claude بتشتغل على جهازك. بتعمل الملفات وتعدّل فيها بنفسها، وبتستأذنك قبل أي تعديل. في Claude Desktop هي تبويب **Code** |
| **Remotion** | الأداة اللي بتحوّل الكود لفيديو MP4. مجانية للأفراد والفرق لحد 3 أشخاص. لو أكتر، محتاج رخصة من remotion.pro |
| **Node.js** | برنامج لازم يبقى متسطّب عشان Remotion يشتغل. نزّل نسخة **LTS** من nodejs.org |
| **التيرمنال** | شاشة بتكتب فيها أوامر. على ويندوز اسمها PowerShell، وعلى الماك Terminal. أو قول لـ Claude يشغّل الأمر بدالك |
| **فريم** | الفيديو صور ورا بعض: 30 صورة في الثانية. فريم 90 = ثانية 3 |
| **مشهد** | جزء من الفيديو ليه فكرة واحدة، زي الهوك أو السعر |
| **render** | تصدير الفيديو كملف MP4 |

## التشغيل على جهازك

محتاج **Node.js** (نسخة 20 أو أحدث).

```bash
cd product-videos
npm install                 # أول مرة بس
npm run setup:skills        # أول مرة بس: بيعلّم Claude قواعد Remotion
npm run dev                 # يفتح المعاينة في المتصفح
npm run render:all          # الإعلانات الأساسية في فولدر out
```

أول render بيحمّل نسخة Chrome خاصة بـ Remotion، فبياخد وقت أطول **مرة واحدة بس**.

## جرّب قبل ما تطلّع الفيديو كله

```bash
npm run try -- P-sink_A-kashta_F-ugc_H-kq                  # أول 3 ثواني بنص الجودة
npm run try -- P-sink_A-kashta_F-ugc_H-kq --from 5 --to 9  # من ثانية 5 لـ 9
npm run try -- P-sink_A-kashta_F-ugc_H-kq --still 2        # صورة من ثانية 2
npm run try -- P-sink_A-kashta_F-ugc_H-kq --theme neon     # بقالب تاني
```

الملفات بتطلع في `out/try`. كده بتشوف التعديل في ثواني بدل ما تستنى الفيديو كله.

## القوالب (8)

| القالب | الشكل | الخط |
|---|---|---|
| `night` | ليلي: كحلي وأصفر | Cairo |
| `clean` | فاتح نظيف: أبيض وأزرق | Tajawal |
| `bold` | جريء: أصفر وأسود وأحمر | Lalezar |
| `desert` | صحراوي دافئ: رملي وبني | Changa |
| `neon` | نيون تقني: بنفسجي غامق ونيون | Readex Pro |
| `fresh` | طبيعي أخضر | Almarai |
| `fun` | مرح: بمبي وبنفسجي | Marhey |
| `luxury` | فاخر: أسود ودهبي | El Messiri |

- كل قالب ليه ألوانه وخطوطه وشكل البوكسات والكروت وحركة ظهور الكلام، **وبيتطبق على كل الفورمات**.
- اختار القالب بـ `theme: "fresh"` في ملف المنتج. **ولو مكتبتهوش، المنتج بياخد قالب ثابت لوحده**، فكل منتج بيطلع بشكل مختلف.
- تقدر تغيّر الخطوط أو الألوان لمنتج واحد بـ `fonts` و`colors` في ملفه.
- تجربة قالب من غير ما تغيّر الملف: `--theme neon` مع أي أمر.

**الخطوط المتاحة (15):** Cairo، وTajawal، وAlmarai، وIBMPlexArabic، وChanga، وElMessiri، وLalezar، وReemKufi (للعناوين بس)، وReadexPro، وNotoKufiArabic، وBalooBhaijaan2، وMarhey، وLemonada، وRubik، وMada. كلها جوه المشروع ومش محتاجة إنترنت، ورخصها في `public/fonts/licenses`.

## الفورمات

| الفورمات | المدة | فيه إيه |
|---|---|---|
| `showcase` | ~32 ث | هوك ← المشكلة ← الحل ← المميزات ← الاستخدامات ← (آراء العملاء) ← السعر ← اطلب الآن |
| `short` | ~14 ث | هوك ← المنتج ← أهم ميزتين ← السعر ← اطلب الآن |
| `static` | صورة | الهوك + المنتج + 3 مميزات + السعر + زرار الطلب |
| `ugc` | ~20 ث | لقطات ملء الشاشة بقطع سريع، والكلام مكتوب عليها بستايل تيك توك |
| `compare` | ~14 ث | قبل وبعد: الطريقة القديمة قصاد المنتج، سطر سطر |
| `reasons` | ~17 ث | 3 أسباب تخليك تطلب المنتج، كل سبب برقم كبير |
| `pov` | ~18 ث | «POV: لما تكون...» في بوكس أبيض، ولقطات سريعة |

في كل الفيديوهات:
- **الهوك ظاهر من أول فريم**، لأن أول فريم هو صورة الفيديو قبل ما يشتغل.
- **شريط تقدّم** رفيع فوق، زي الستوري.
- **مؤثرات صوتية**: ووش مع الانتقال، ودينج مع السعر، وبوب مع ضغطة الزرار. اتعملت جوه المشروع ومن غير حقوق. `sfx: false` في ملف المنتج بيقفلها.

## اللقطات الحقيقية

1. حط الفيديوهات في `public/products/<اسم-المنتج>/clips/`.
2. ضيفها في `clips` في ملف المنتج. كل لقطة ليها نوع (`role`):

| النوع | معناه | بتظهر فين |
|---|---|---|
| `hook` | لقطة تشد في الأول | أول مشهد |
| `problem` | المشكلة أو الطريقة القديمة | مشهد المشكلة (UGC) |
| `before` | البديل القديم | خانة «قبل» في المقارنة |
| `unbox` | فتح الكرتونة | مشهد ظهور المنتج |
| `demo` | المنتج وهو شغال | أي مكان ملهوش لقطة مخصوصة |
| `feature` | ميزة معينة (`feature: "<id الميزة>"`) | مشهد الميزة دي |
| `result` | النتيجة | آخر لقطة في UGC، وخانة «بعد» في المقارنة |
| `lifestyle` | المنتج في مكان استخدامه | الاستخدامات، و POV |
| `talking` | حد بيتكلم عن المنتج | أول مشهد |

```ts
clips: [
  { id: "unbox", file: "products/portable-sink/clips/unbox.mp4", role: "unbox" },
  // فيديو طويل: نفس الملف، كل لقطة من ثانية لثانية
  { id: "pump", file: "products/portable-sink/clips/full.mp4", role: "feature", feature: "foot", start: 12, end: 16 },
  // حد بيتكلم: خلّي صوته يشتغل
  { id: "review", file: "products/portable-sink/clips/review.mp4", role: "talking", audio: true },
],
```

3. شغّل `npm run clips -- sink` عشان تشوف اللي اتضاف والأماكن اللي لسه بتستخدم صور.

أو ابعت الفيديوهات لـ Claude، وهو هيتفرّج عليها ويصنّفها ويضيفها.

## الموسيقى

حط ملف موسيقى **ليك حق استخدامه** في `public/music`، واكتب في ملف المنتج: `music: "music/اسم-الملف.mp3"`. بتشتغل بصوت واطي تحت الفيديو، وبتختفي بالتدريج في الآخر.

## طريقة الـ Winner Creative (بأمر خاص)

الطريقة دي **مبتشتغلش غير لما تطلبها**:

```bash
npm run winner -- P-sink_A-kashta_F-showcase_H-kq          # كل النسخ
npm run winner -- P-sink_A-kashta_F-showcase_H-kq --only hook   # فرع واحد: angle | hook | format
npm run winner -- P-sink_A-kashta_F-showcase_H-kq --dry    # الخطة بس من غير فيديوهات
npm run winner -- P-sink_A-kashta_F-showcase_H-kq --formats ugc,static   # الفورمات اللي تتجرّب
```

من الإعلان الكسبان بيطلّع نسخ، **كل نسخة بتغيّر عنصر واحد بس**:
- **هوك تاني** لنفس الزاوية والفورمات ← بيختبر الهوك
- **فورمات تاني** لنفس الزاوية والهوك ← بيختبر الفورمات
- **نفس باترن الهوك** (سؤال، فضول، رقم...) على **زاوية تانية** ← بيختبر الزاوية

**القالب بيفضل ثابت** في كل النسخ.

وفي Claude: اكتب **«وينر»** أو `/winner`، وClaude هيمشي على الطريقة كلها: يحدد الوينر، ويكتب الهوكات الناقصة، ويطلّع النسخ، ويسجّلها.

قبل ما يبقى عندك وينر، تقدر تختبر الزوايا: `npm run angles -- sink`

`results/ads-log.csv` بيتفتح في Excel. كل إعلان بيطلع بأمر `winner` أو `angles` بيتسجّل فيه، وانت بتملا أرقامه بعد ما يشتغل.

## إضافة منتج جديد

1. حط صور المنتج في `public/products/<اسم-المنتج>/`.
2. انسخ `src/products/portable-sink.ts` لملف جديد وعدّل:
   - `id` و `code`: معرّف المنتج واسمه القصير في أسماء الإعلانات
   - `name` و `tagline` و `price` و `currency` (`IQD` أو `SAR`)
   - `oldPrice` و `offer` (اختياري)
   - `features`: المميزات، كل واحدة بـ `id` وأيقونة
   - `angles`: الزوايا، كل زاوية بمشاكلها وترتيب مميزاتها واستخداماتها. واختياري: `pov` و`compare`
   - `hooks`: الهوكات، كل هوك تابع لزاوية (`angle`) وليه باترن (`pattern`)
   - `theme` (اختياري): القالب
   - `clips` (اختياري): اللقطات الحقيقية
   - **بيانات حقيقية بس (اختياري):** `reviews` تقييمات العملاء، و`faq` أسئلة وأجوبة، و`limited` جملة زي «الكمية محدودة». **متكتبهمش غير لو حقيقيين.**
   - `music` (اختياري): الموسيقى
3. ضيف المنتج في `src/products/index.ts`.

أو ببساطة قول لـ Claude: «ضيف منتج جديد» وابعتله التفاصيل والصور.

## نصايح للشغل مع Claude

| النصيحة | ليه |
|---|---|
| **اطلب تعديل واحد في المرة**، ومحدد بالمشهد والثانية. مثلًا: «في مشهد السعر، خلّي الرقم أكبر» | Claude ميعدّلش حاجات مطلبتهاش |
| **Plan Mode** (اضغط Shift+Tab مرتين) قبل أي تعديل كبير | Claude يكتب الخطة ويستنى موافقتك قبل ما يلمس أي ملف |
| **`/clear`** بين المهام المختلفة | يبدأ محادثة جديدة، فيوفّر توكنز ويخلي Claude مركّز |
| **`/compact`** لما المحادثة تطول | يلخّص اللي فات من غير ما تبدأ من الأول |
| **Esc** | يوقف Claude فورًا لو ماشي في اتجاه غلط |
| **`npm run try`** قبل الفيديو الكامل | بتشوف النتيجة في ثواني |

القواعد الثابتة للمشروع مكتوبة في `CLAUDE.md`، وClaude بيقراها أول كل جلسة.
